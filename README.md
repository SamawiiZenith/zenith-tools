# Zenith Tools ❄️

A small collection of command-line utilities built while learning Python.

## Features

- 🌡️ Convert Celsius and Fahrenheit
- 📏 Convert kilometres and miles
- 📝 Count words and characters
- 🛡️ Handle invalid numeric input

## Requirements

- Python 3.10 or newer

## Run locally

```bash
python main.py
```

On some Windows installations, use:

```bash
py main.py
```
